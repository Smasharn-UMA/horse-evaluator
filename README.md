# Horse Evaluator 3.0 — Sprint 1.2.1

## 修正内容

Sprint 1.2でユニオンURL取得がiPhone／iPad上で安定しなかったため、CORS制限に依存しない「ページ本文から取得」を追加しました。その他の登録・編集・検索・JSON機能は変更していません。

## 推奨手順

1. ユニオンの募集馬詳細ページをSafariで開きます。
2. ページ本文を「すべて選択」してコピーします。
3. Horse Evaluatorで［募集馬を登録］を開きます。
4. URLを入力します。
5. 「ページ本文」欄へコピーした内容を貼り付けます。
6. ［ページ本文から取得］を押します。
7. 自動反映された内容を確認して保存します。

［URL取得を試す］も残していますが、GitHub Pagesから外部サイトを取得する制限により、端末や通信環境によって失敗します。安定運用には「ページ本文から取得」を使用してください。

## 取得対象

- 年度
- クラブ
- 募集番号
- 馬名・募集名
- 性別
- 生年月日
- 父・母・母父
- 所属
- 厩舎
- 生産牧場
- 募集総額
- 一口価格
- 測尺（馬体重・体高・胸囲・管囲）

写真・動画の自動抽出、AI評価は未実装です。

## 更新方法

1. 現在のアプリでJSONバックアップを保存します。
2. ZIPを展開します。
3. `index.html`、`style.css`、`app.js`、`README.md`、`RELEASE_NOTES.md`をGitHubリポジトリのルートで置き換えます。
4. GitHub Pagesを再読み込みします。
5. ヘッダーが「Sprint 1.2.1」になっていることを確認します。

既存データはそのまま引き継がれます。
