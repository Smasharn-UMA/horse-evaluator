# Horse Evaluator 3.0 Core — Sprint 1.5.3

iPhone / iPad向けの募集馬管理アプリです。ブラウザのlocalStorageへ保存し、JSONバックアップ・復元に対応します。

## Sprint 1.5.3
- 募集番号・馬名・父・母・母父・厩舎・牧場などの横断検索
- 年度・クラブ・性別・所属・お気に入りの複合フィルター
- 募集価格の昇順／降順、一口価格の昇順を追加
- 表示条件のリセット
- 表示条件を端末内に保持
- 一覧カードへ性別・毛色・生産牧場を追加
- 絞り込み時に「表示頭数 / 全登録頭数」を表示
- Sprint 1.5.2までのシルク・ユニオン本文取込とJSON互換を維持
