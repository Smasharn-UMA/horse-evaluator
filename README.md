# Horse Evaluator 3.0 Version 1.8.20.8

## Teacher Analysis Foundation

Version 1.8.20.6を基準に、教師データ解析の初期基盤を追加したDevelopment版です。

### 追加機能

- 教師データだけを分析用JSONとして一括書き出し
- 重賞勝ち群と非重賞勝ち群の一次比較
- 項目別の平均差、標準化効果量、データ充足率の表示
- 解析日時・教師データ数の内部保存
- 欠損値を項目ごとに除外する解析方式

### 使い方

1. 教師データの各馬に「競走実績」と評価点を登録します。
2. データ管理の「教師データ一次解析」を押します。
3. 重賞勝ち群と比較群の項目差を確認します。
4. ChatGPTで詳細解析する場合は「教師データ解析JSON」を書き出します。

### 注意

この版の解析は初期の記述統計です。表示された差を、そのまま因果関係や将来確率とは扱いません。評価基準の統一、比較群の充実、性別・芝ダート等の層別化を進めた後に2026 Season Modelの重みへ反映します。

## v1.8.20.9 Teacher Label Auto Class

教師データ解析の競走実績ラベルは、原則として登録済みの現在クラスを自動参照します。

- 未勝利 → 未勝利
- 1勝クラス → 勝ち上がり
- 2勝 / 3勝クラス → 2勝以上
- OP / オープン → オープン
- 重賞勝利 / GⅠ勝利は「教師データ管理」の手動チェックで補完
- 従来の「競走実績」欄は旧データ互換・補助入力として保持

Teacher Data Analyzerでは、クラスから自動判定できた非重賞馬も比較群に含めます。

### Physical Analysis 2026（開発版）
詳細画面に、写真・歩様・測尺のみを根拠とする身体能力プロファイルを表示します。5領域の水準、突出領域数、高水準領域数、ボトルネック、補償力、後躯→体幹→前躯の全身連動を直感的に確認できます。2026年の閾値は暫定値で、教師データ増加時に再検証する前提です。
