# Horse Evaluator 3.0 Core — Sprint 1.7.3c

一口馬主向けの出資判断支援アプリです。ブラウザ内保存で動作し、GitHub Pagesへ配置できます。

## Sprint 1.7.3cの主な改善

- ChatGPTの回答全文を、そのまま貼り付けてAI評価を反映
- 前後の説明文、`json` / `horse-evaluator`コードブロック、スマート引用符に対応
- 募集ページからの写真自動取得を廃止し、端末からの手動登録へ統一
- 表示条件を募集馬一覧の上部へ移動
- 一覧写真をトリミングせず全体表示
- 詳細画面を常に先頭から表示
- 詳細画面上部に閉じるボタンを追加

## 写真登録

1. 募集馬編集画面の「写真を追加」を押します。
2. iPhone・iPadの写真ライブラリから画像を選択します。
3. 並び順と代表写真を設定します。
4. カルテを保存します。

写真URLの直接追加も利用できますが、安定運用には端末内写真の登録を推奨します。

## ChatGPT写真評価の反映

1. 「AI連携テンプレートをコピー」を押します。
2. ChatGPTへテンプレートと募集写真を送ります。
3. ChatGPTの回答を全文コピーします。
4. 「ChatGPTの回答全文を反映」欄へ貼り付けます。
5. 「回答全文から評価を反映」を押します。

JSONだけを切り出す必要はありません。

## 更新前の注意

必ず旧版からJSONバックアップを書き出してください。GitHub Pagesのファイル更新だけではブラウザ内データは通常保持されますが、端末やブラウザの変更に備えてバックアップを推奨します。
