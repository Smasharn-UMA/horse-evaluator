# Horse Evaluator 3.0 Core — Sprint 1.5.1 Phase 1

## 実装内容
- シルク募集ページ本文の貼り付け取込
- シルク／ユニオン形式の自動判定
- 解析結果を登録フォームへ反映して確認後に保存
- 毛色、在厩場所、クラスのデータ項目を追加
- Sprint 1.4.1 JSONとの互換性を維持

## シルク取込手順
1. 「募集馬を登録」を開く
2. 形式を「自動判定」または「シルク」にする
3. シルク募集馬ページ本文を貼り付ける
4. 「ページ本文から取得」を押す
5. 解析結果を確認して「保存」する

## 注意
写真・動画の自動抽出、AI評価は未実装です。
