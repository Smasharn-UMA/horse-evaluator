# Horse Evaluator 3.0 Version 1.8.20

教師データ管理基盤を追加した更新版です。

- 1頭1レコードを維持
- 募集年度を変更せず教師データ属性を追加
- 年度・教師データ・出資馬・比較対象外で表示切替
- 教師ランク、最終評価、満足度、タグ、振り返りを保存
- 類似馬エンジンの比較対象を教師データへ変更
- 既存JSONを自動移行


## Version 1.8.20
教師コメント、教師データ充足度、JSONスキーマVersion 2、重複ID自動修復を追加しました。
