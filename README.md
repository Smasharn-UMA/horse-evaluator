# Horse Evaluator 3.0 — Version 1.8.20.6 Dev

本文貼り付けから測尺を自動抽出する共通 Measurement Parser を追加した開発版です。

## 今回の主な対応

- 馬体重・体高・胸囲・管囲を本文から自動抽出
- キャロット・シルク・ユニオンの各本文Parserから共通測尺Parserを利用
- 複数時点の測尺がある場合、内部では履歴として保存
- 一覧・詳細・編集画面は従来どおり最新値のみ表示
- 測尺の取込元、URL、取込時刻を内部保存
- 既存JSONをSchema Version 4へ自動移行

## 対応表記例

- `馬体重：420kg`
- `体高 150cm　胸囲 168cm　管囲 19.8cm`
- `【2026年5月下旬】馬体重：358kg`
- `2026年7月 馬体重 400kg 体高 150cm 胸囲 170cm 管囲 20.0cm`

本文取込後は入力欄に反映された数値を確認してから保存してください。URL取得はブラウザや相手サイトの通信制限により失敗する場合があります。


## Version 1.8.20.6 追加修正
- 年齢表記がないキャロット現役馬本文（例：`牡 鹿毛 '20/3/22生`）を新規登録できるよう修正。
- 馬名由来の言語表記を「英語」限定から「伊語」などの各言語表記へ拡張。
