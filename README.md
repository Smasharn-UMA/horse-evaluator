# Horse Evaluator 3.0 — Sprint 1.1

Sprint 1の機能に、募集価格表示と厩舎所属管理を追加した更新版です。

## 追加・変更点

- 募集総額と1口価格を一覧・詳細画面に同時表示
- 所属区分を追加：美浦／栗東／地方
- 所属による絞り込み
- 厩舎名と所属を別項目で保存
- 生産牧場・育成牧場の入力候補を追加（自由入力も可能）
- Sprint 1の保存データとJSONを自動移行
- JSONバージョンを `3.0.1` に更新

## 更新手順

1. 現在のアプリで「JSONバックアップ」を実行します。
2. ZIPを展開します。
3. GitHubリポジトリの `index.html`、`style.css`、`app.js`、`README.md`、`RELEASE_NOTES.md` を置き換えます。
4. GitHub Pagesの公開URLを再読み込みします。
5. 既存データは同じブラウザであれば自動的に引き継がれます。

## 注意

- データは端末ごとのブラウザ内に保存されます。
- iPhoneとiPadの自動同期はありません。
- 更新前のJSONバックアップを推奨します。
- 写真・動画URLは保存・表示用です。AI解析はまだ未実装です。
