# Horse Evaluator 3.0 Core — Sprint 1.7.0

一口馬主の募集馬情報・評価・出資判断を、iPhone／iPadのブラウザ内で管理するローカルWebアプリです。

## Sprint 1.7.0の主な変更

- 募集馬の詳細画面上部に「出資判断カルテ」を追加
- 総合点、推奨度、自信度を一画面に集約
- 入力済み評価から、AI総括、強み、気になる点、出資推奨理由を自動生成
- C評価では見送り理由を表示
- B評価でも明確な懸念がある場合は、条件付きの見送り理由を表示
- 一口価格15万円以上を高額募集の確認項目として表示
- 評価モデル画面に、欠けていたS／A／B推奨度基準入力欄を追加
- Sprint 1.6.2cの総合点内訳、シルク・ユニオン本文取込、JSONバックアップ互換を維持

## 起動方法

1. ZIPを展開します。
2. フォルダ内の `index.html` をSafariで開きます。
3. 必要に応じて共有メニューからホーム画面へ追加します。

端末内データはブラウザのlocalStorageへ保存されます。更新前には「JSONバックアップ」を実行してください。

## 出資判断カルテの使い方

1. 募集馬を登録または編集します。
2. 評価シートの各項目を1〜5点で入力します。
3. 保存後、馬カードの「詳細」を開きます。
4. 上から順に「結論 → 根拠 → 詳細」を確認します。

自動生成文は入力済み評価の要約です。写真・動画そのものを解析する機能は、Sprint 1.7.1以降で追加予定です。
