# Horse Evaluator 3.0 Core — Sprint 1.6.1

## 追加機能
- 各馬に1〜5点の評価シートを保存
- 馬体8項目、歩様8項目、配合・厩舎・生産育成3項目
- 未評価を選択可能（共通点集計では対象外）
- 競走実績ラベルと主戦場を保存
- 体質リスクと総合コメントを保存
- 詳細画面と一覧カードに入力済み評価の平均を表示
- Sprint 1.5.3以前のJSONを自動移行

## 評価データの目的
Sprint 1.6.2以降で、重賞勝利馬・GⅠ勝利馬などの特徴を集計し、新規募集馬の「活躍馬共通点一致度」を算出するための基盤です。

ZIPを展開し、GitHub Pages上の既存ファイルをすべて差し替えてください。画面上部に `Sprint 1.6.1` と表示されます。
