# Horse Evaluator 教師データ・ブラインド再評価 Phase 1

## この版で実装したもの
- 教師データJSONの読込
- 実績・メディア条件・検索による対象抽出
- 表示中の全選択 / 無作為抽出
- 匿名ID（BLIND-0001等）の生成
- AIへ渡す情報から馬名・血統・厩舎・生産・価格・実績を除外
- 再評価パッケージJSONの出力
- 秘密の照合表JSONの出力
- ChatGPT用ブラインド再評価プロンプトTXTの出力
- 再評価結果JSONの取込
- 旧評価を保持したまま、新評価との差を項目別・実績別に集計

## 重要
このPhase 1は既存教師データを一切上書きしません。

教師データJSONには写真・動画本体が含まれていないため、この版ではAIへメディアを自動送信しません。
Horse Evaluator本体のIndexedDBに保存された写真・動画を利用するには、現在運用中の最新版ソースへ統合する必要があります。

## 使用手順
1. index.html をSafariで開く（GitHub Pages等のHTTPSホスト推奨）。
2. 「教師JSONを読み込む」で `horse-evaluator-teacher-dataset-....json` を選ぶ。
3. 実績・メディア条件を絞り、再評価対象を選択。
4. 「匿名IDを生成」。
5. 「再評価パッケージJSON」と「照合表JSON（秘密）」を保存。
6. AI再評価時は秘密の照合表を渡さない。
7. ChatGPT用プロンプトと対象馬の写真・歩様動画を用いて評価。
8. 指定形式の結果JSONを保存し「再評価結果JSONを取り込む」。
9. 項目別・実績別の差分を確認する。
