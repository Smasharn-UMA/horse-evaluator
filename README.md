# Horse Evaluator 3.0 — Sprint 1.3

iPhone・iPad向けの募集馬管理アプリです。GitHub Pagesで動作し、データは端末ブラウザのlocalStorageへ保存します。

## Sprint 1.3の主な追加

- ユニオン本文から募集口数を自動抽出
- 1口価格を100円単位で入力・保存・表示
- 1口価格が本文にない場合のみ、募集総額÷募集口数から100円単位で補完
- 募集時PRの自動抽出・保存
- 内部管理IDを自動付与
- 既存Sprint 1.2.2データとの互換性を維持

## 更新方法

1. 現在のアプリでJSONバックアップを保存します。
2. GitHub Pagesのリポジトリで `index.html`、`style.css`、`app.js`、`README.md`、`RELEASE_NOTES.md` を置き換えます。
3. iPhone・iPadでページを再読み込みし、画面上部が `Sprint 1.3` になっていることを確認します。

## ユニオン本文取込

ユニオン募集馬ページをSafariで開き、本文をコピーして「ページ本文」欄へ貼り付けます。「ページ本文から取得」を押すと、募集口数・1口価格・募集時PRを含む基本情報を自動反映します。
