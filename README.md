# Horse Evaluator 3.0 Core — Sprint 1.5.2 Phase 2

iPhone / iPad向けの募集馬管理アプリです。ブラウザのlocalStorageへ保存し、JSONでバックアップ・復元できます。

## Sprint 1.5.2の追加内容

- ユニオン募集ページ本文の取込精度を改善
- シルク／ユニオン形式の自動判定を改善
- クラブ別フィルター
- 性別（牡・牝・せん）フィルター
- 募集時測尺は1セットのみ保存

## ユニオン本文取込

募集馬登録画面の「募集ページ本文取込」へ本文を貼り付け、「ページ本文から取得」を押してください。以下を可能な範囲で抽出します。

- 募集番号、募集名
- 性別、毛色、生年月日
- 父、母、母父
- 所属、厩舎
- 生産牧場、育成牧場
- 募集総額、募集口数、一口価格
- 馬体重、体高、胸囲、管囲
- 募集時PR

複数の測尺が本文に含まれる場合は、最新側の1セットだけをフォームへ反映します。

## データ互換性

Sprint 1.4.1およびSprint 1.5.1のJSONデータを継続利用できます。更新前にJSONバックアップを保存してください。
