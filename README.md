# Horse Evaluator 3.0 — Version 1.8.20.4 Dev

キャロット現役馬 Parser 2.0を追加した開発版です。

## 今回の主な対応

キャロット現役馬ページの本文に、次の形式が含まれる場合に取り込めます。

- `牡 5歳 鹿毛 '21/4/17生`
- `Sixpence（英語） 馬名の由来…父キズナ × 母○○(BMS:○○)`
- `関東 田中博 厩舎 生産ノーザンファーム`
- `総口数400口 募集総額5,000万円 1口出資額125,000円`
- `平地OP(6-1-0-6)`

本文取込後は必ず入力内容を確認してから保存してください。URL取得は相手サイトやブラウザの通信制限により失敗する場合があります。その場合はページ本文を貼り付けてください。
