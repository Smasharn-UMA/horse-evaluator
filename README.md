# Horse Evaluator 3.0 — Sprint 1.4.1 Step1

Sprint 1.3を基礎にしたJSON互換性修正版です。新機能は追加せず、バックアップ復元の安全性を優先しています。

## Step1の変更

- Sprint 1.3（version 3.1.0）バックアップJSONを読み込み可能
- `horses` / `records` / `items` / 配列形式に対応
- 不足フィールドを既定値で補完
- 読込前の現在データをlocalStorageへ退避
- 復元後に保存し、再読込して件数一致を検証
- エラー理由を画面に表示
- 「OK」で置換、「キャンセル」で追加・更新

## 安全な更新手順

1. Sprint 1.3でJSONバックアップを保存します。
2. GitHub Pages上の5ファイルを本ZIPの内容へ置き換えます。
3. 画面上部に `Sprint 1.4.1 Step1` と表示されることを確認します。
4. 「JSON復元」でSprint 1.3のバックアップを選びます。
5. 完全復元する場合は確認画面で「OK」を選択します。
6. 復元完了後、登録頭数と主要データを確認します。

データ保存先は従来どおり、この端末・ブラウザのlocalStorageです。
