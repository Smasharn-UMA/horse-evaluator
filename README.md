# Horse Evaluator 3.0 — Sprint 1.7.1

一口馬主の出資判断を支援する、iPhone・iPad向けローカルWebアプリです。

## Sprint 1.7.1
- 1頭につき最大8枚の写真登録
- 端末写真の自動圧縮（長辺1200px、JPEG）
- 写真URL登録
- 代表写真、並び替え、削除
- 写真全体へのコメント
- AI写真評価10項目とAI写真総括
- ChatGPT連携テンプレートのコピー
- AI評価JSONの反映
- 写真・AI評価をJSONバックアップへ含める

## 注意
写真はブラウザの端末内ストレージ（localStorage）に保存します。大量・高解像度の写真では容量上限に達する場合があります。写真追加後は必ずJSONバックアップを書き出してください。
