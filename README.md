# Horse Evaluator 3.0 — Sprint 1.4

iPhone・iPad・Safari・GitHub Pages向けの募集馬管理アプリです。ログインは不要で、募集馬データは端末のブラウザに保存します。

## Sprint 1.4の主な機能

- 年度・クラブ・所属・性別・お気に入りによる複合検索
- ダッシュボード（登録頭数、お気に入り、性別内訳、最終更新）
- ユニオン募集馬ページ本文からの基本情報取込
- 写真の複数登録、サムネイル、拡大表示、削除
- 歩様動画の登録・再生・差し替え・削除（1頭につき1本）
- 募集価格、募集口数、一口価格、測尺、PR、メモの管理
- JSONバックアップ・復元
- AI評価欄の表示準備
- 更新履歴

## 保存仕様

- 文字・数値データ：localStorage
- 写真・動画：IndexedDB
- JSONバックアップには写真・動画本体を含みません
- 写真・動画は登録した端末・ブラウザ内にのみ保存されます

## GitHub Pagesへの導入

1. ZIPを展開します。
2. `index.html`、`app.js`、`style.css`をGitHubリポジトリ直下へアップロードします。
3. GitHub Pagesを有効にします。
4. 更新後に古い画面が出る場合はSafariを再読み込みしてください。

## 更新時の注意

Sprint 1.3の既存データは自動移行します。更新前にSprint 1.3からJSONバックアップを保存してください。
