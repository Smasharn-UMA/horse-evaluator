# Horse Evaluator 3.0 Core — Sprint 1.7.1b

一口馬主向けの出資判断支援アプリです。ブラウザ内保存で動作し、GitHub Pagesへ配置できます。

## Sprint 1.7.1bの主な機能

- 複数写真登録、代表写真、並び替え、削除
- 写真全体へのコメント
- AI写真評価10項目とAI写真総括
- AI連携テンプレートと評価JSON反映
- ユニオン・シルク募集ページからの写真取得試行
- JSONバックアップ／復元

## 募集ページから写真を取得する手順

1. 募集馬カルテ上部の「募集馬詳細ページURL」にURLを入力します。
2. 写真管理欄の「募集ページから写真取得」を押します。
3. 追加された写真を確認します。
4. 不要な写真を削除し、代表写真を選びます。
5. カルテを保存します。

### ユニオン

次の形式に対応します。

- `https://www.union-oc.co.jp/id/4003`
- `https://www.union-oc.co.jp/id/4003#open_PHOTO`

### シルク

次の形式を認識し、ページ内画像の抽出を試行します。

- `https://www.silkhorseclub.jp/horse_info/boshu/detail/2025001`

シルクはサイト側の制限により取得できない場合があります。その場合は写真を端末へ保存して登録してください。

## 更新前の注意

必ず旧版からJSONバックアップを書き出してください。GitHub Pagesのファイル更新だけではブラウザ内データは通常保持されますが、端末やブラウザの変更に備えてバックアップを推奨します。
