# Horse Evaluator 3.0 — Sprint 1.2

## 新機能：ユニオン募集馬URL自動取込（第1段階）

募集馬登録・編集画面でユニオンの募集馬詳細ページURLを入力し、［URLから基本情報を取得］を押すと、次の項目を入力欄へ反映します。

- 年度
- クラブ
- 募集番号
- 馬名・募集名
- 性別
- 生年月日
- 父・母・母父
- 所属
- 厩舎
- 生産牧場
- 募集総額
- 一口価格
- 測尺（馬体重・体高・胸囲・管囲）

抽出後は必ず内容を確認してから保存してください。ユニオン側のページ構造変更により、一部項目が取得できなくなる場合があります。

## 重要な制約

- Sprint 1.2のURL自動取込はユニオン専用です。
- 写真・動画の自動抽出は未実装です。
- AIによる馬体・歩様評価は未実装です。
- GitHub Pagesからユニオンへ直接アクセスできない場合、外部のテキスト取得サービス（r.jina.ai）を経由します。通信環境やサービス制限により失敗する場合があります。
- データはブラウザのlocalStorageへ保存され、iPhoneとiPad間では自動同期されません。

## 更新方法

1. 現在のアプリでJSONバックアップを保存します。
2. ZIPを展開します。
3. `index.html`、`style.css`、`app.js`、`README.md`、`RELEASE_NOTES.md`をGitHubリポジトリのルートで置き換えます。
4. GitHub Pagesの公開画面を再読み込みします。
5. ヘッダーが「Sprint 1.2」になっていることを確認します。

既存のSprint 1／1.1データはそのまま引き継がれます。
